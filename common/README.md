# Common

## 📌 Descrição

Contém estruturas e definições partilhadas entre os vários programas.

## 🧠 Conteúdo

* Estruturas de comunicação:

  * MSG_CMD
  * MSG_ALERTA
  * MSG_ID
* Constantes globais
* Definições de Named Pipes
* Definições de memória partilhada

## 📂 Estrutura

* `include/` – headers comuns

## ⚠️ Notas

Evita duplicação de código entre os programas.
