# Programa Monitor

## 📌 Descrição

O monitor permite visualizar os alertas ativos no sistema através de uma interface gráfica.

## 🧠 Funcionalidades

* Listagem de alertas ativos
* Visualização dos placares associados
* Atualização em tempo real

## 🖥️ Interface

* Interface gráfica Win32
* Menu com opções:

  * Configuração de visualização
  * Informação do grupo
  * Sair

## 🔗 Comunicação

* Recebe dados do central via memória partilhada

## 📂 Estrutura

* `src/` – código fonte
* `include/` – headers

## ⚠️ Notas

* Pode existir mais do que uma instância
* Não é necessário para o funcionamento da plataforma
